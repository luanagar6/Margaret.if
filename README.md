# Margaret.if

**Conheça mulheres que transformaram o mundo. Aprenda com suas histórias. Teste seus conhecimentos.**

O **Margaret.if** é uma biblioteca virtual desenvolvida para o **HackaIF**, dentro da temática *Ciência Delas*. O projeto tem como objetivo dar visibilidade às contribuições de mulheres em diferentes áreas do conhecimento, como ciência, tecnologia, engenharia, saúde, ciências sociais, artes e cultura.

A plataforma reúne matérias informativas e quizzes educativos, proporcionando uma experiência de aprendizagem interativa e acessível.

## Objetivos

- **Dar visibilidade:** divulgar histórias e contribuições de mulheres que marcaram suas áreas de atuação.
- **Educar:** apresentar informações de maneira acessível, interessante e confiável.
- **Promover a representatividade:** destacar a diversidade de mulheres que participam da construção do conhecimento.
- **Incentivar o aprendizado:** utilizar quizzes para reforçar o conteúdo apresentado nas matérias.
- **Aproximar conhecimento e tecnologia:** explorar recursos digitais para tornar a aprendizagem mais dinâmica.

## Como funciona?

A experiência da plataforma é organizada em três etapas:

### 1. Descubra

Explore matérias e conteúdos sobre mulheres que contribuíram para a ciência, a tecnologia, a cultura e a sociedade.

### 2. Aprenda

Conheça suas trajetórias, realizações e contribuições por meio de conteúdos informativos e referências para aprofundamento.

### 3. Teste seus conhecimentos

Responda a quizzes relacionados aos conteúdos estudados e reforce o aprendizado de maneira interativa.

## Áreas de conhecimento

O Margaret.if busca abranger diferentes áreas:

- **Ciências Exatas e Tecnologia:** matemática, física, computação e engenharias.
- **Ciências Biológicas e Saúde:** biologia, medicina, genética e biotecnologia.
- **Ciências Humanas e Sociais:** história, psicologia, sociologia e educação.
- **Artes e Cultura:** música, literatura, cinema e artes visuais.
- **Meio Ambiente:** ecologia, sustentabilidade e conservação.

## Tecnologias

O desenvolvimento da plataforma utiliza:

- **HTML5:** estrutura das páginas.
- **CSS3:** estilos visuais e responsividade.
- **JavaScript:** interatividade e funcionamento dos quizzes.
- **Node.js:** ambiente de execução JavaScript no servidor.
- **Express:** gerenciamento do servidor e das rotas da aplicação.
- **Prettier:** formatação e padronização do código.

### Tecnologias em estudo

Também estão sendo consideradas ferramentas para aprimorar a organização e a produção de conteúdo:

- **DeepSeek:** auxílio na classificação, organização e elaboração de resumos.

A utilização de inteligência artificial deverá contar com revisão humana, verificação das informações e registro das fontes consultadas.

## Como executar o projeto

### Pré-requisitos

- [Node.js](https://nodejs.org/)
- Git (opcional, para clonar o repositório)

### 1. Clone o repositório

```bash
git clone https://github.com/luanagar6/Margaret.if.git
```

### 2. Entre na pasta do projeto

```bash
cd Margaret.if
```

### 3. Instale as dependências

```bash
npm install
```

### 4. Inicie o servidor

```bash
npm start
```

### 5. Acesse a aplicação

Abra o navegador e entre em:

```text
http://localhost:3000
```
