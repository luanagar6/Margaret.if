# Margaret.if

O Margaret.if é uma biblioteca virtual desenvolvida para o HackaIF, na temática **Ciência Delas**. O projeto busca dar visibilidade às contribuições de mulheres em diferentes áreas do conhecimento, como ciência, tecnologia, saúde, ciências sociais, artes e cultura.

A plataforma reúne conteúdos sobre mulheres que marcaram a história, permitindo que os visitantes conheçam suas trajetórias, descubram suas contribuições e participem de quizzes interativos.

## Objetivos

- **Dar visibilidade**: divulgar histórias e contribuições de mulheres que marcaram suas áreas de atuação.
- **Educar**: apresentar informações de maneira acessível e interessante.
- **Promover a representatividade**: destacar a diversidade de mulheres que participam da construção do conhecimento.
- **Incentivar o aprendizado**: utilizar quizzes interativos para despertar a curiosidade e reforçar conhecimentos.
- **Aproveitar a tecnologia**: explorar ferramentas de automação e inteligência artificial para auxiliar na pesquisa e na organização de conteúdo.

## Como funciona?

A plataforma é organizada em três etapas principais:

### 1. Descubra

O usuário explora as categorias e conhece mulheres que contribuíram para a ciência, a tecnologia, a cultura e a sociedade.

### 2. Aprenda

Cada perfil apresenta informações sobre a trajetória de uma mulher, suas realizações e a importância de suas contribuições.

### 3. Teste seus conhecimentos

A plataforma conta com duas propostas de quiz:

- **Quiz de personalidade**: ajuda o visitante a descobrir quais áreas do conhecimento combinam mais com seus interesses.
- **Quiz educativo**: permite testar conhecimentos sobre diferentes áreas por meio de perguntas de múltipla escolha, explicações das respostas e pontuação final.

O quiz educativo é organizado por categoria, permitindo que o visitante escolha o tema que deseja explorar.

## Áreas de conhecimento

O Margaret.if busca abranger diferentes áreas do conhecimento:

- **Computação**: programação, tecnologia e desenvolvimento de software.
- **Ciências Biológicas**: vida, saúde e pesquisa científica.
- **Ciências Sociais**: comportamento humano, sociedade e relações sociais.
- **Cultura e Arte**: música, literatura, cinema e diferentes formas de expressão artística.

## Automação e inteligência artificial

O projeto prevê a utilização de ferramentas de automação e inteligência artificial para auxiliar na pesquisa, classificação e organização dos conteúdos.

- **DeepSeek**: ferramenta prevista para auxiliar na classificação, organização e elaboração de resumos.

A utilização dessas ferramentas deverá ser acompanhada de revisão humana, verificação das informações e registro das fontes consultadas, contribuindo para a confiabilidade do conteúdo publicado.

## Como executar

### Pré-requisitos

- Node.js instalado.
- Git instalado, caso deseje clonar o repositório.

### Instalação

1. Clone o repositório:

   ```bash
   git clone https://github.com/luanagar6/Margaret.if.git
   ```

2. Entre na pasta do projeto:

   ```bash
   cd Margaret.if
   ```

3. Instale as dependências:

   ```bash
   npm install
   ```

4. Inicie o servidor:

   ```bash
   npm start
   ```

5. Acesse o endereço indicado no terminal.
